# EDS conversion log — fortstreet-h × oneAZ v3.2 (reskin → deploy)

Flow: `reskin` (Figma donor). Prototypes = the gated reskin pages `stardust/reskin/pages/<slug>.html`
(archetypes: `index`, `about-us`, `school-life-bell-times`, `learning-and-support-wellbeing`).
Content = `content/**.html`, generated by `stardust/reskin/renderers/to-da.mjs` from the captured content
models (never retyped). Runtime: `stardust/runtime-contract.json` (current aem-boilerplate main:
formatted-only buttons, `a.button.primary|secondary` in `p.button-wrapper`, `wrapTextNodes`).

- **D-EDS-1 — one `<h1>`.** index has no h1 in the source: its hero heading (h4) is authored as `<h1>` (text
  unchanged). Pages with a second source `<h1>` (bell-times "Attendance", wellbeing "Student Health") author it as `<h2>`.
- **D-EDS-2 — glyph words.** Source icon-font ligature words (`east`, `keyboard_arrow_right`) are content bytes:
  card arrows are authored as `<p>east</p>` and the cards block renders the paragraph as the arrow glyph
  (text kept, font-size 0 + CSS arrow), so the served text stays byte-equal to the source.
- **D-EDS-3 — `about:error`.** The source's own broken image on school-life-newsletters and our-community-foundation
  is omitted (EDS must never ship `about:error`); recorded in `stardust/reskin/da-deviations.json`.
- **D-EDS-4 — D1 advisories.** `breadcrumbs`, `links`, `cta-banner` and single-card `cards` are single-cell blocks
  over prose by design: each is a donor module with bespoke chrome-like styling (separator glyphs, gold rule,
  bordered box), not plain default content.
- **Fonts.** Inter (OFL) + Roboto Slab (Apache 2.0, the served stand-in for the licensed Lexia) self-hosted in
  `fonts/`, declared in `styles/fonts.css`; tokens keep the donor strings verbatim (`fonts/LICENSING.md`).
- **Foundation.** `styles/styles.css` is generated from `stardust/reskin/donor-tokens.json` (root-tokens + every
  token as a path-named custom property: `--palette-*`, `--type-*`, `--layout-*`, `--buttons-*`, `--cards-*`).
  Block CSS uses ONLY those variables (no literal colours, fonts, radii or spacing — reskin "no donor-token drift").
